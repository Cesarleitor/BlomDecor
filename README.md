# BlomDecor

Projeto web da **BlomDecor** desenvolvido com **HTML, CSS e JavaScript**, com foco em presença online, apresentação institucional e exibição de produtos.

## Sobre o projeto

Este projeto foi criado para representar a presença digital da BlomDecor na web, oferecendo uma interface visual para apresentação da marca e um catálogo de produtos organizado de forma simples e intuitiva.

A proposta do site é unir identidade visual, navegação clara e experiência agradável para o usuário, permitindo visualizar os produtos e conhecer melhor a empresa.

## Funcionalidades

- Página inicial com apresentação da marca
- Catálogo de produtos
- Interface web responsiva e visualmente organizada
- Exibição de imagens dos produtos
- Estrutura separada entre conteúdo, estilo e lógica

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- `index.html` → página inicial do site
- `catalogo.html` → página de catálogo de produtos
- `style.css` → estilização da aplicação
- `produtos.js` → lógica relacionada aos produtos
- `img/` → imagens utilizadas no projeto
